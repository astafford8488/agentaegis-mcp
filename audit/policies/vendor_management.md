# AgentAegis — Vendor Management Policy

> **Organization:** AgentAegis · **Version:** 1.0 · **Owner:** Information Security Team
>
> **Effective:** 2026-05-04 · **Next review:** 2027-05-04 · **Frameworks:** SOC2, ISO27001

## 1. Purpose

Establish requirements for assessing and managing the security risks associated with AgentAegis's third-party vendors and service providers.

## 2. Vendor Classification

- Critical: Vendors with access to sensitive data or critical systems
- Standard: Vendors with limited access or non-sensitive roles
- Low: Vendors with no data access or system connectivity

## 3. Assessment Requirements

- Critical vendors: Annual security assessment, SOC 2 report review, contractual security requirements
- Standard vendors: Security questionnaire review, contractual data protection terms
- Low vendors: Basic due diligence only

## 4. Contractual Requirements

- Data processing agreements where applicable
- Security incident notification requirements (24-48 hours)
- Right to audit clause
- Data return/destruction upon contract termination
- Compliance with applicable regulations

## 5. Ongoing Monitoring

Critical vendors reviewed annually. Security incidents involving vendors trigger immediate reassessment.
